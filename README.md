# Brndr API Docs

Interactive Swagger UI documentation for the **Brndr** backend API.

## Live docs

Published at:

```
https://brndrapp.github.io/Backend_Docs/
```

## Using the docs

Browse endpoints, request/response schemas, and parameters in the UI. Use
**Try it out** to send live requests against a backend.

> The spec's default server is `localhost:8080`, so **Try it out** targets a
> local backend by default. To hit a deployed server, change the server/host
> field in the UI.

Routes accept and return `application/x-protobuf` payloads unless otherwise
noted.
